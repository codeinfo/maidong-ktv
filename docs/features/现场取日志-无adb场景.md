# 现场取日志（没有 adb 时）

> 日期：2026-11-15　|　适用版本：**0.1.1（versionCode 4）及以后**　|　场景：盒子在客户现场，没有 adb、不方便连电脑

## 一、三种办法，按现场条件挑

| 方式 | 需要什么 | 适合 |
| --- | --- | --- |
| **① 手机浏览器下载**（推荐） | 手机与盒子同一局域网（同一 WiFi / 同一交换机） | 有人在现场、手上有手机 |
| **② U 盘拷贝** | 一个 U 盘 + 盒子能识别（OTG/自带 USB 口） | 现场完全没有网络、也没有手机 |
| ③ 连回 adb | USB 线 + 电脑 | 设备能拿到手边时最快，`tools/verify.ps1` 直接跑 |

## 二、方式①：手机浏览器直接下载（0.1.1 起内置）

盒子本来就跑着「手机点歌」服务（端口 8765），现在同一套服务多开了三个日志地址：

| 地址 | 内容 |
| --- | --- |
| `http://<盒子IP>:8765/logs` | 日志列表页（带大小、可直接点开看） |
| `http://<盒子IP>:8765/logs.zip` | **打包下载全部日志**，最适合一次性发回 |
| `http://<盒子IP>:8765/app.log`（实际为 `/logs/app.log`） | 单个文件原始文本 |

**操作步骤**

1. 盒子上 **设置 → 网络设置**，弹窗现在会直接显示：
   ```
   IP: 192.168.x.x
   手机遥控端口: 8765
   日志下载: http://192.168.x.x:8765/logs
   ```
2. 手机连同一局域网，浏览器打开上面那条「日志下载」地址。
3. 点「打包下载全部日志（zip）」，得到一个 `maidong-logs.zip`，里面是 `app.log` 与 `app.log.1`（每个 ≤ 2 MB）。
4. 把 zip 发回来即可。

> 注意：8765 没有鉴权，只应在内网使用；现场如果是公共网络，用完可以把手机点歌服务关掉。

## 三、方式②：U 盘拷贝

日志就写在外部存储上，路径固定：

```
/sdcard/MaidongKTV/logs/app.log      当前日志（超过 2 MB 滚动）
/sdcard/MaidongKTV/logs/app.log.1    上一份
```

用盒子自带的文件管理器（或 U 盘助手类工具）把这两个文件复制到 U 盘根目录，再拿到电脑上打开即可。曲库、歌曲在同级目录 `songs/`，不用一起拷。

## 四、日志里能查到什么（按 TAG 检索）

| TAG | 关键内容 | 对应问题 |
| --- | --- | --- |
| `SongSourceRouter` | `音源=… 歌曲=… 地址=…`、`所有音源均未取到地址` | 取不到下载地址（三级路由全失败） |
| `IgebaMediaDownloader` | `媒体机拒绝请求 HTTP xxx`、`下载停滞 …ms，已中断`、`下载异常 written=… total=…` | i歌霸分段下载失败 |
| `SongOkDownloadManager` | `空间不足，拒绝下载`、`i歌霸文件校验未通过`、重试记录 | 空间/校验/重试 |
| `Download` | `下载失败：<歌名>` + 异常类型与消息 | **0.1.1 新增**，旧版本这条只弹 toast、不落盘 |
| `KeyTrace` | `key=… focus=…`、`qa_open 已打开 …` | 遥控器焦点、页面跳转 |
| `KtvApplication` / `TvUiScale` | 启动、屏幕与缩放因子 | 启动异常、显示适配 |

## 五、这次补的两处日志缺口

改之前，「下载失败」有两条分支只做 `toast` + `Log.e`（只进 logcat，而这台 4.4 ROM 的 logcat 经常读不到），等于现场没有证据。0.1.1 把这两处都改成同时写 `AppLog`：

- `MainActivity` 旧下载任务的 `catch (Exception)` → `AppLog.e("Download", "下载失败：${song.title}", e)`
- `MainActivity` 直连下载的 `catch (Exception)` → `AppLog.e("Download", "下载失败（直连）：${song.title}", e)`

## 六、安全边界

- 日志只记参数摘要与结果，下载地址经 `AppLog.maskUrl()` 处理（去掉签名参数），不含密码、Cookie、账号。
- `logs/` 目录不入 git，也不随 APK 打包发布。
- 8765 服务只在应用运行时监听，退出即关；没有账号体系，不要映射到公网。
