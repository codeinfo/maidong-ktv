## 六、结论与取舍建议

1. **播放内核不同**：本地以 ijkplayer 为核心（`KtvVideoView.kt` 中 `tv.danmaku`/ijk 相关引用 56 处，配套 `app/libs/original-ijk-runtime.jar` 与 `jniLibs/armeabi-v7a/libijk*.so`）；上游已换成 ExoPlayer(media3) + 原生 FFmpeg 双引擎（`player/ExoPlaybackEngine.kt`、`KtvPlaybackEngine.kt`、`NativePlaybackEngine.kt`、`cpp/ffmpeg_player.cpp`、`third_party/ffmpeg` 预编译 `.so`）。整分支合并实质是更换播放内核，**不适合直接 merge**。
2. **数据层不同**：本地保留 `MuseDatabase.kt`、`SongApiClient.kt`、`TsDecryptor.kt`、`DatabaseBootstrapper.kt` 及 `database_publish/database`（94 个数据库文件）；上游改为 `CatalogAssets` + `IgebaCatalogBootstrapper`，并把 `igeba_catalog.db`、`singer_portraits.db`、`pinyin_chars.json` 放进 assets，同时新增 OpenList 直读（`OpenListBrowser`/`OpenListCatalog`/`OpenListClient`/`OpenListPaths`）。
3. **本地已在自行移植 iGeba**：14 个上游同名文件已存在于本地工作区但未跟踪，且本地版本普遍比上游版本更长（如 `IgebaCatalog.kt` 上游新增 162 行 / 本地 450 行独有内容），说明是二次改造而非原样拷贝。**移植应以本地版本为基准逐处对照上游，不要直接覆盖**。
4. **可直接吸收（低风险）**：`docs/`（50 个文档）与 `tools/`（11 个脚本）为纯文档与运维脚本；`app/src/main/assets/mobile/`（`app.css`/`app.js`/`index.html`/`logo.css`）是手机端 Web 控制页，属新功能可整块引入。
5. **需谨慎评估**：`third_party/ffmpeg` 108 个预编译 `.so`（armeabi-v7a/x86/x86_64）会明显增大包体；`app/build.gradle`（上游 +40 / 本地 32 行独有）、`AndroidManifest.xml`、本地独有的 `gradle.properties` 涉及构建配置，需逐项对齐。
6. **改动量最大处**：`MainActivity.kt`（上游独有 2205 行 / 本地独有 1120 行）、`SongOkDownloadManager.kt`（500 / 406）、`SongListAdapter.kt`（321 / 105）、`LocalRemoteServer.kt`（195 / 44）；`KtvVideoView.kt` 则是本地独有 351 行对上游 20 行，印证播放层已分道。
